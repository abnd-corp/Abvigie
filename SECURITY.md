# Signaler une faille

Si vous trouvez une faille dans Abvigie, **ne l'ouvrez pas en issue publique**.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis **Report a vulnerability**. Le service publie aussi `/.well-known/security.txt` avec ce contact.

Nous répondons sous quelques jours. Aucun délai de correction n'est garanti tant que le support n'est pas organisé (voir « À couvrir avant le premier client » dans la [charte](https://github.com/abnd-corp/gouvernance/blob/main/CHARTE.md)).

Le modèle de menace et les protections en place sont décrits dans [docs/securite.md](docs/securite.md).
